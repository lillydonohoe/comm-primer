## How I built this site

My process for building this website started with my Theory Primer. I used the main ideas as a foundation for this website. I was able to split up all the important information into separate pages to organize my website. I used simplified language as well in order to target a broader audience, making it easier to understand these ideas. 

**Design and Technology**

I created this website using Copilot GitHub, which is hosted through GitHub Pages. I was able to paste a prompt into Copilot GitHub, which created my Median, then I was able to use code on GitHub to edit my website. 

The pages follow a progression, starting with understanding the problem, to understanding the effects, to knowing how to go about the problem. The final page shares advice on using AI without losing your voice. 

**My Role and AI's Role**

AI was used to assist in the website's initial coding and technical setup. I remained responsible for the content and edits that AI supported me with. I chose what to carry over from my Theory Primer to my website, and which examples to share. I made my own communication choices while creating this website.
